- The Create Event, Edit Event, one-off, Edit Repeating Event and Organization
  Event Defaults dialogs list their sections in a sidebar instead of a row of
  tabs, with a search that finds any setting by name, description or keyword
  and jumps to it. Press `/` or Ctrl/Cmd+K to search. Sections holding a field
  with a validation error carry a warning marker. On phones a section picker
  replaces the sidebar.
