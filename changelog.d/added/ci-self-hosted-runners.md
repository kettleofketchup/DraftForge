- An optional `prepare` job in the Playwright workflow builds missing dev images and the test database once per pull request on a self-hosted home runner, for allowlisted authors' same-repo pull requests only. Test jobs never wait on it for more than 180 s and fall back to building themselves. It stays off until the `SELF_HOSTED_RUNNERS` and `HOME_RUNNER_AUTHORS` repository variables are set; see `docs/development/ci-runners.md`.
- `docker::buildx` and `docker::db::build` take `--mode=pr --pr=<n>`, which pushes only `draftforge-ci/<img>:pr-<n>-<hash>` and never a trusted tag or the shared build cache, and `just ci::check-runs-on` checks which jobs may use the home runner.
