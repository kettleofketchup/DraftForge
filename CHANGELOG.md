# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning 2.0.0](https://semver.org/spec/v2.0.0.html).

Do not edit this file in a PR: add a fragment under `changelog.d/` (see its README).
`just version::set X.Y.Z` assembles the fragments into a release section, commits
"Updated version to X.Y.Z", tags `X.Y.Z` and pushes; the tag builds the release images.

Releases made before this file was added are not listed here; see the git tags and history.
